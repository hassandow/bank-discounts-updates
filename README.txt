منظومة الخصومات المصرفية - الإصدار 1.0.2

هذه الحزمة تضيف فحص التحديثات إلى تطبيق Electron.
المستودع المرتبط:
https://github.com/hassandow/bank-discounts-updates

الحفاظ على الإصدارات:
- الإصدار 1.0.1 يبقى محفوظاً في GitHub Release/tag باسم v1.0.1.
- الإصدار 1.0.2 هو الإصدار الأساسي الجديد، ورقم نسخته مضبوط في package.json.
- لا تخلط ملفات التثبيت بين الإصدارين. لكل إصدار Release مستقل وملفات dist خاصة به.

بناء ملف التثبيت:
1) ثبّت Node.js إصدار LTS على جهاز Windows.
2) نزّل ملفات المشروع كاملة من المستودع وفك ضغطها في مجلد مستقل.
3) شغّل: إنشاء-ملف-التثبيت.bat
4) بعد اكتمال البناء ستجد ملفات التثبيت وملفات التحديث في مجلد dist.

نشر الإصدار 1.0.2:
- أنشئ GitHub Release جديداً بالوسم v1.0.2.
- ارفع جميع الملفات الناتجة داخل dist، وبالأخص ملف Setup وملف latest.yml وأي ملفات .blockmap.
- لا ترفع ملفات المصدر وحدها وتتوقع أن يعمل التحديث؛ يجب أن تكون ملفات البناء موجودة في الإصدار المنشور.
- لا تحذف Release v1.0.1؛ اتركه محفوظاً كسجل للإصدار السابق.

التحديثات اللاحقة:
- ارفع رقم version في package.json (مثلاً 1.0.3).
- ابنِ البرنامج من جديد.
- أنشئ Release جديداً بالوسم المطابق (v1.0.3) وارفع ملفات dist الجديدة.

مهم:
- التحديث التلقائي خاص بنسخة Windows المثبتة المبنية بواسطة Electron، وليس بفتح index.html مباشرة في Chrome.
- يجب أن تكون ملفات التحديث المنشورة في GitHub Release متاحة للبرنامج. إذا كان المستودع خاصاً فقد يحتاج إعداد صلاحية تنزيل مناسبة.
- هذه الحزمة لا تنقل البيانات القديمة ولا تغيّر مكان تخزينها. احتفظ بنسخة احتياطية من بياناتك قبل اعتماد أي تحديث.
- لم يتم إنشاء Setup.exe داخل GitHub؛ يتم إنشاؤه عند تشغيل ملف BAT على Windows مع اتصال بالإنترنت.
- لا تضع كلمة مرور GitHub أو مفاتيح الوصول داخل ملفات المشروع أو ترسلها في المحادثة.
