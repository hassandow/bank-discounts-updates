منظومة الخصومات المصرفية - الإصدار 1.0.8

هذه نسخة إصدار 1.0.8 مبنية على مصدر الإصدار 1.0.7، مع تصحيح رقم الإصدار داخل package.json وتحديث تعليمات البناء. تم الحفاظ على ملفات الواجهة وآلية التخزين المحلي ومفتاح البيانات كما هي.

المستودع:
https://github.com/hassandow/bank-discounts-updates

البناء على Windows:
1) ثبّت Node.js إصدار LTS.
2) افتح مجلد المشروع.
3) شغّل: إنشاء-ملف-التثبيت.bat
4) بعد نجاح البناء ستجد ملفات التثبيت والتحديث داخل مجلد dist.

نشر الإصدار 1.0.8:
- أنشئ GitHub Release جديداً بالوسم v1.0.8.
- ارفع جميع الملفات الناتجة داخل dist، وبالأخص Setup.1.0.8.exe وlatest.yml وأي ملفات .blockmap.
- لا تخلط ملفات dist بين الإصدارات، ولا تحذف الإصدارات السابقة.

ملاحظات مهمة:
- التحديث التلقائي يعمل في نسخة Windows المثبتة المبنية بواسطة Electron، وليس عند فتح index.html مباشرة في Chrome.
- ملف Setup.exe لا يتم إنشاؤه على GitHub تلقائياً؛ يجب بناؤه على Windows عبر ملف BAT.
- احتفظ بنسخة احتياطية من بياناتك قبل تثبيت أي تحديث.
- لم يتم تغيير مفتاح التخزين المحلي daily_salary_system_v1 أو حذف بيانات المستخدم.
- لا تضع كلمة مرور GitHub أو مفاتيح الوصول داخل ملفات المشروع.
