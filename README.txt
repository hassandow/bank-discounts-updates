منظومة الخصومات المصرفية - الإصدار 1.0.1

هذه الحزمة تضيف فحص التحديثات إلى تطبيق Electron.
المستودع المرتبط:
https://github.com/hassandow/bank-discounts-updates

بناء ملف التثبيت:
1) ثبّت Node.js إصدار LTS على جهاز Windows.
2) فك ضغط الحزمة في مجلد عادي.
3) شغّل: إنشاء-ملف-التثبيت.bat
4) بعد اكتمال البناء ستجد ملفات التثبيت وملفات التحديث في مجلد dist.

نشر التحديث الأول:
- أنشئ GitHub Release بالوسم v1.0.1.
- ارفع جميع الملفات الناتجة داخل dist، وبالأخص ملف Setup وملف latest.yml وأي ملفات .blockmap.
- لا ترفع ملفات المصدر وحدها وتتوقع أن يعمل التحديث؛ يجب أن تكون ملفات البناء موجودة في الإصدار المنشور.

التحديثات اللاحقة:
- ارفع رقم version في package.json (مثلاً 1.0.2).
- ابنِ البرنامج من جديد.
- أنشئ Release جديداً بالوسم المطابق (v1.0.2) وارفع ملفات dist الجديدة.

مهم:
- هذا التحديث التلقائي خاص بنسخة Windows المثبتة المبنية بواسطة Electron، وليس بفتح index.html مباشرة في Chrome.
- هذه الحزمة لا تنقل البيانات القديمة ولا تغيّر مكان تخزينها. اختبر نسخة احتياطية من بياناتك قبل اعتماد أي تحديث.
- لم يتم إنشاء Setup.exe داخل هذه الحزمة؛ يتم إنشاؤه عند تشغيل ملف BAT على Windows مع اتصال بالإنترنت.
- لا تضع كلمة مرور GitHub أو مفاتيح الوصول داخل ملفات المشروع أو ترسلها في المحادثة.
