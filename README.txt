منظومة الخصومات المصرفية - الإصدار 1.0.3

هذا الإصدار يحافظ على وظائف الإصدار 1.0.2 ويحسن رسائل فحص التحديثات والتنبيه عند توفر تحديث أو عدم توفره أو حدوث خطأ.

المستودع المرتبط:
https://github.com/hassandow/bank-discounts-updates

الحفاظ على الإصدارات:
- الإصدار 1.0.1 يبقى محفوظاً في GitHub Release/tag باسم v1.0.1.
- الإصدار 1.0.2 يبقى محفوظاً في GitHub Release/tag باسم v1.0.2.
- الإصدار 1.0.3 هو الإصدار الجديد، ورقم نسخته مضبوط في package.json.
- لا تخلط ملفات التثبيت بين الإصدارات. لكل إصدار Release مستقل وملفات dist خاصة به.

بناء ملف التثبيت:
1) ثبّت Node.js إصدار LTS على جهاز Windows.
2) نزّل ملفات المشروع كاملة من المستودع وفك ضغطها في مجلد مستقل.
3) شغّل: إنشاء-ملف-التثبيت.bat
4) بعد اكتمال البناء ستجد ملفات التثبيت وملفات التحديث داخل مجلد dist.

نشر الإصدار 1.0.3:
- أنشئ GitHub Release جديداً بالوسم v1.0.3.
- ارفع جميع الملفات الناتجة داخل dist، وبالأخص ملف Setup وملف latest.yml وأي ملفات .blockmap.
- لا ترفع ملفات المصدر وحدها وتتوقع أن يعمل التحديث؛ يجب أن تكون ملفات البناء موجودة في الإصدار المنشور.
- لا تحذف Releases السابقة؛ اتركها محفوظة كسجل للإصدارات السابقة.

التحديثات اللاحقة:
- ارفع رقم version في package.json.
- ابنِ البرنامج من جديد.
- أنشئ Release جديداً بالوسم المطابق وارفع ملفات dist الجديدة.

مهم:
- التحديث التلقائي خاص بنسخة Windows المثبتة المبنية بواسطة Electron، وليس بفتح index.html مباشرة في Chrome.
- يجب أن تكون ملفات التحديث المنشورة في GitHub Release متاحة للبرنامج.
- هذه الحزمة لا تنقل البيانات القديمة ولا تغيّر مكان تخزينها. احتفظ بنسخة احتياطية من بياناتك قبل اعتماد أي تحديث.
- ملف Setup.exe لا يتم إنشاؤه على GitHub تلقائياً؛ يتم إنشاؤه عند تشغيل ملف BAT على Windows مع اتصال بالإنترنت.
- لا تضع كلمة مرور GitHub أو مفاتيح الوصول داخل ملفات المشروع أو ترسلها في المحادثة.
